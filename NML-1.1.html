Метанормативный статус и правило иерархии

Правило иерархии (RuleNML):
∀r∀r′( (RuleNML(r) & RuleBase(r′) & Conflicts(r, r′)) → Priority(r′, r) )
Метанормативная оговорка: При любом конфликте между рекомендациями настоящего файла и требованиями базовой МФО-НС-12.3.4 приоритет имеет базовая методология. Области: r ∈ NORM_NML, r′ ∈ NORM_BASE.

Новые предикаты (строго качественные и диагностические)

ПредикатОпределение
MoreSpecific(arg₁, arg₂)Аргумент arg₁ имеет более узкий контекст, чем arg₂. arg₁, arg₂ ∈ ARG.
WeakerLink(arg, link)link является наименее верифицируемым звеном в цепочке arg. arg ∈ ARG, link ∈ STEP.
CausallyRelevant(prop₁, prop₂)Свойства каузально связаны. prop₁, prop₂ ∈ PROPERTY.
FloatingConclusion(c)Заключение поддерживается несколькими независимыми цепочками. c ∈ CONCL.
SkepticalConsequence(Σ, φ)φ верно во всех расширениях. Σ ⊆ PROP, φ ∈ PROP.
CredulousConsequence(Σ, φ)φ верно хотя бы в одном расширении. Σ ⊆ PROP, φ ∈ PROP.
EpistemicPlaceholder(ph, n)Минимально возможное содержание ph для нормы n. ph ∈ PLACEHOLDER, n ∈ NORM.
SyncreticDefeasible(s, c)Синкретический маркер s отзывает формальный вывод c. s ∈ SINKR, c ∈ CONCL.
StrictSubset(c′, c) (ПРАВКА NML-5)Содержание c′ является строгим подмножеством содержания c (все свойства c′ входят в c, но не наоборот). c′, c ∈ CONT. Устраняет недекларируемость символа ⊂.

Модификации существующих протоколов МФО-НС-12.3.4

1. Дополнение к протоколу ПОНД-27 (п. 6.42) – Ограниченная циркумскрипция (Правка А-3, NML-5)

Критическая коррекция: Запрещено применение онтологического CWA. Применяется ограниченная циркумскрипция предикатов.

Формальная запись (исправлена по М-1, правка NML-5):
∀n( Norm(n, D) & Unavailable(D) → Circ(Content(n)) )
где Circ(Content(n)) ↔ ∀c( Content(n) = c → ¬∃c′( Content(n) = c′ ∧ StrictSubset(c′, c) ) )
Статус: [ЭПИСТЕМИЧЕСКИЙ_ПЛЕЙСХОЛДЕР].

2. Дополнение к протоколу ПМР-20 (п. 6.34) – Принцип weakest link и пример (Правка NML-7)

Новый шаг: При наличии нескольких механизмов реализации применять качественный принцип weakest link: оценивать механизм по его наименее верифицируемому звену (WeakerLink). Ограничение (IV.8): Запрещено преобразовывать в числовые веса.

Пример применения принципа Weaker Link [ПРИМЕР ДЛЯ СТРУКТУРЫ — НЕ ИСПОЛЬЗОВАТЬ] (Правка NML-7):

МеханизмСлабое звено (WeakerLink)Категориальный уровень верификацииРешение
Механизм АОтсутствие верифицированной методики расчётаК_практики ограничен категорией [ВНУТРЕННЯЯ_ЭКСПЕРТИЗА]Сравниваем категории: [ВНУТРЕННЯЯ_ЭКСПЕРТИЗА] выше по уровню материальной обеспеченности, чем [НЕТ_МАТЕРИАЛЬНОЙ_ОСНОВЫ].

Приоритет отдаётся Механизму А.

Числовые коэффициенты (0.4, 0.1) не используются (антиредукционистский контур IV.8).
Механизм БОтсутствие субъекта реализации и материальных ресурсовК_практики ограничен категорией [НЕТ_МАТЕРИАЛЬНОЙ_ОСНОВЫ] (закон II.22, доп. 12.0)

3. Дополнение к протоколу ПКЛР-17 (п. 6.32) – Жёсткие триггеры и связка с СИНКР-ТРАНС (Правка А-2, NML-6)

Запрет каскадной активации: Автоматическая активация NML исключительно на основании факта активации Аргументационной логики запрещена.

Триггеры активации NML (уточнено по М-2, правка NML-6):

  1. Обнаружение конфликта норм в ходе проверок (а)–(г) протокола ПАПП-24.
  2. Обнаружение аномалии в данных (протокол ПВП-ОД, п. 6.3).
  3. Наличие флага [НЕРАЗРЕШИМЫЙ_КОНФЛИКТ].
  4. Наличие флага [SINKR_DETECTED]. Важное уточнение (NML-6): При данном триггере NML активируется не как независимый параллельный процесс, а как операционный инструмент внутри контура Т-1 (диатопическая трансляция мифологем) протокола СИНКР-ТРАНС. Это обеспечивает координацию с принципом асимметричной интеграции и предотвращает горизонтальное смешение модулей (запрет 5, п. I.14.6).
