Для всех r, для всех r':

Области: r принадлежит NORM_EXP, r' принадлежит NORM_BASE.

МОДУЛЬ: ТЕОРЕТИЧЕСКОЕ ОСНОВАНИЕ
И ДИАЛЕКТИЧЕСКАЯ ПОДЧИНЁННОСТЬ
================================================================================

Регистр: [ФОРМАЛЬНАЯ СИСТЕМА] для теории игр,
[ОПЕРАЦИОННЫЙ ИНСТРУМЕНТ] для многокритериальной оптимизации.

Атрибуция по ПИР-ЭУ (п. 6.1 МФО-НС-13.3.3):
Статус: [ДЕЙСТВИТЕЛЬНОСТЬ] — конспект лекций ВМК МГУ,
предоставленный пользователем, прямое сличение с текстом
проведено.

Согласно конспекту лекций ВМК МГУ "Теория игр и исследование
операций" (Морозов В.В.), теория игр формализует стратегическое
взаимодействие агентов через следующие основные разделы:

1. Антагонистические игры и седловые точки (Лекции 1-2):
   Игра задаётся тройкой Г = <X, Y, F(x,y)>, где X, Y —
   множества стратегий, F — функция выигрыша. Седловая точка
   (x0, y0) определяется неравенством:
   F(x, y0) <= F(x0, y0) <= F(x0, y)
   для всех x из X, для всех y из Y.
   Нижнее значение игры: V = sup по x из X, inf по y из Y,
   F(x, y).
   Верхнее значение игры: V_верх = inf по y из Y, sup по x
   из X, F(x, y).
   Лемма: V <= V_верх. Седловая точка существует тогда и
   только тогда, когда V = V_верх.

2. Матричные игры и смешанные стратегии (Лекции 3-5):
   Матричная игра задаётся матрицей A = (a_ij), m строк на
   n столбцов. Смешанная стратегия — вероятностное
   распределение на множестве чистых стратегий. Основная
   теорема матричных игр: всякая матричная игра имеет
   решение в смешанных стратегиях.

3. Непрерывные игры (Лекции 3-4):
   Игра Г = <X, Y, F> с X = [a,b], Y = [c,d],
   F непрерывна на произведении. Основная теорема
   непрерывных игр: всякая непрерывная игра имеет решение
   в смешанных стратегиях.

4. Неантагонистические игры (Лекции 9-10):
   Игра двух лиц Г = <X, Y, F(x,y), G(x,y)>.
   Равновесие по Нэшу: F(x0,y0) >= F(x,y0) для всех x;
   G(x0,y0) >= G(x0,y) для всех y.
   Оптимальность по Парето и по Слейтеру.
   Биматричные игры и их решения.

5. Иерархические игры (Лекция 11):
   Игры Г1 и Г2 (модели Гермейера). Равновесие по
   Штакельбергу. Стратегия наказаний. Теорема Гермейера:
   наилучший гарантированный выигрыш равен
   max{K, M}.

6. Многокритериальная оптимизация (Лекции 12-14):
   Векторная оценка: W(x) = (W1(x), ..., Ws(x)).
   Оптимальность по Парето и по Слейтеру.
   Бинарные отношения. Ядро бинарного отношения.
   Свёртка критериев.

7. Задачи оптимального распределения ресурсов (Лекции 17-18):
   Задача максимизации минимального эффекта.
   Принцип уравнивания (Теорема 3.8).
   Лемма Гиббса (Теорема 3.10): необходимое и достаточное
   условие оптимальности через равенство производных.
   Критерий Гросса (Теорема 3.11) для дискретных задач.
   Задача поиска объекта.

Диалектическое снятие:

Теория игр в МФО-НС-13.3.3 выступает как формальный
инструмент уровня Антитезиса и контроля границ применимости.
Она операционализирует:

- Закон II.4 (Противоречие как источник развития): конфликт
  интересов между субъектами формализуется как антагонистическая
  или неантагонистическая игра. Равновесие по Нэшу фиксирует
  момент, в котором противоречие между стратегиями агентов
  локально снято, но не устранено системно.

- Закон II.14 (Конкретность истины): множество стратегий и
  функций полезности фиксирует границы применимости решения.
  Оптимальность по Парето и Слейтеру задаёт конкретные условия,
  при которых решение может быть изменено.

- Закон II.22 (Практика как критерий истины): функция
  полезности строится на основе материального положения
  субъекта (этап 3 ПМПВ), а не постулируется априорно.

Противоречие между формальной оптимальностью (математически
доказанная оптимальная стратегия) и материальной конкретностью
(реальное поведение субъектов, зависящее от контекста,
культуры, истории) снимается через требование верификации
функций полезности через ПМПВ. Формальная модель даёт
структуру; материальная верификация даёт содержание.

СЛОВАРНОЕ ДОПОЛНЕНИЕ ИГРЫ-1

Правило расширения словаря: словарь ИГРЫ-1 является
расширением словаря МФО-НС-13.3.3 (дополнения 12.1-12.3.1)

(единое правило иерархии).

--- НОВЫЕ ПРЕДМЕТНЫЕ ОБЛАСТИ (7 областей) ---

Область 1: GAME
Содержание: Игры (антагонистические, иерархические,
кооперативные, биматричные, многошаговые).
Переменные: Г, Г1, Г2.

Область 2: STRATEGY
Содержание: Стратегии (чистые и смешанные).
Переменные: x, y, p, q.

Область 3: UTILITY
Содержание: Функции полезности.
Переменные: u, u1, u2.

Область 4: CRITERIA_SET
Содержание: Наборы критериев (для Парето/Слейтер).
Переменные: C.

Область 5: RESOURCE_SET
Содержание: Ресурсы для распределения.
Переменные: R, A.

Область 6: PLAYER
Содержание: Участники игры (агенты, центр, производитель).
Переменные: a, b, a1, a2.

Область 7: EQUILIBRIUM_TYPE
Содержание: Типы равновесий (Нэш, Штакельберг, Парето,
Слейтер, седловая точка).
Переменные: et.

--- НОВЫЕ КОНСТАНТЫ ---

Константа 1: ТИП_АНТАГОНИСТИЧЕСКАЯ.
Определение: Антагонистическая игра (нулевая сумма).
Область: EQUILIBRIUM_TYPE.

Константа 2: ТИП_ИЕРАРХИЧЕСКАЯ.
Определение: Иерархическая игра (центр — производитель,
лидер — последователь).
Область: EQUILIBRIUM_TYPE.

Константа 3: ТИП_КООПЕРАТИВНАЯ.
Определение: Кооперативная игра (возможны соглашения).
Область: EQUILIBRIUM_TYPE.

Константа 4: ТИП_БИМАТРИЧНАЯ.
Определение: Биматричная игра (две матрицы выигрышей).
Область: EQUILIBRIUM_TYPE.

Константа 5: ТИП_МНОГОШАГОВАЯ.
Определение: Многошаговая игра с полной информацией.
Область: EQUILIBRIUM_TYPE.

Константа 6: РАВНОВЕСИЕ_НЭША.
Определение: Равновесие по Нэшу.
Область: EQUILIBRIUM_TYPE.

Константа 7: РАВНОВЕСИЕ_ШТАКЕЛЬБЕРГА.
Определение: Равновесие по Штакельбергу.
Область: EQUILIBRIUM_TYPE.

Константа 8: ОПТИМУМ_ПАРЕТО.
Определение: Оптимальность по Парето.
Область: EQUILIBRIUM_TYPE.

Константа 9: ОПТИМУМ_СЛЕЙТЕРА.
Определение: Оптимальность по Слейтеру.
Область: EQUILIBRIUM_TYPE.

Константа 10: СЕДЛОВАЯ_ТОЧКА.
Определение: Седловая точка антагонистической игры.

--- НОВЫЕ ПРЕДИКАТЫ (20 предикатов, строго качественные) ---

Предикат 1: ТипИгры(Г, тип).
Определение: Игра Г имеет тип "тип".
Области: Г принадлежит GAME, тип принадлежит EQUILIBRIUM_TYPE.

Предикат 2: МатричнаяИгра(Г, A).
Определение: Игра Г задана матрицей выигрышей A.
Области: Г принадлежит GAME, A — матрица.

Предикат 3: ИерархическаяИгра(Г, Г1, Г2).
Определение: Игра Г является иерархической: центр Г1,
производитель Г2.
Области: Г, Г1, Г2 принадлежат PLAYER.

Предикат 4: СмешаннаяСтратегия(p, Г).
Определение: Вектор p является смешанной стратегией в игре Г.
Области: p принадлежит STRATEGY, Г принадлежит GAME.

Предикат 5: ЗначениеИгры(Г, V).
Определение: Значение (цена) игры Г равно V.
Области: Г принадлежит GAME, V — числовое значение.

Предикат 6: СедловаяТочка(x, y, Г).
Определение: Пара (x, y) является седловой точкой в игре Г.
Области: x, y принадлежат STRATEGY, Г принадлежит GAME.

Предикат 7: ДоминирующаяСтратегия(x, Г).
Определение: Стратегия x доминирует все остальные в игре Г.
Области: x принадлежит STRATEGY, Г принадлежит GAME.

Предикат 8: РавновесиеНэша(x, Г).
Определение: Ситуация x является равновесием по Нэшу в игре Г.
Области: x принадлежит STRATEGY, Г принадлежит GAME.

Предикат 9: РавновесиеШтакельберга(x, y, Г).
Определение: Пара (x, y) является равновесием по Штакельбергу
в иерархической игре Г.
Области: x, y принадлежат STRATEGY, Г принадлежит GAME.

Предикат 10: ОптимумПарето(x, C).
Определение: Стратегия x оптимальна по Парето относительно
набора критериев C.
Области: x принадлежит STRATEGY, C принадлежит CRITERIA_SET.

Предикат 11: ОптимумСлейтера(x, C).
Определение: Стратегия x оптимальна по Слейтеру относительно
набора критериев C.
Области: x принадлежит STRATEGY, C принадлежит CRITERIA_SET.

Предикат 12: РаспределениеГиббса(Х, Ф, А).
Определение: Распределение Х ресурса А по лемме Гиббса для
функций эффективности Ф.
Области: Х принадлежит STRATEGY, Ф принадлежит UTILITY,
А принадлежит RESOURCE_SET.

Предикат 13: ФункцияПолезности(a, u).
Определение: Субъект a имеет функцию полезности u.
Области: a принадлежит PLAYER, u принадлежит UTILITY.

Предикат 14: ПолезностьВерифицирована(u).
Определение: Функция полезности u верифицирована через ПМПВ
(этап 3: картирование структурных интересов).
Области: u принадлежит UTILITY.

Предикат 15: КонфликтИнтересов(а1, а2).
Определение: Субъекты а1 и а2 имеют конфликтующие интересы
(деонтический конфликт или различие функций полезности).
Области: а1, а2 принадлежат PLAYER.

Предикат 16: МногокритериальныйЗапрос(Т).
Определение: Запрос Т содержит несколько конкурирующих
критериев.
Области: Т принадлежит TASK.

Предикат 17: ЗадачаРаспределенияРесурсов(Х, Ф, А).
Определение: Сформулирована задача распределения ресурса А
между альтернативами с функциями эффективности Ф.
Области: Х принадлежит STRATEGY, Ф принадлежит UTILITY,
А принадлежит RESOURCE_SET.

Предикат 18: ВекторнаяПолезность(в, а1, а2).
Определение: Векторная функция полезности в для субъектов
а1 и а2 из разных качественных моделей.
Области: в принадлежит UTILITY, а1, а2 принадлежат PLAYER.

Предикат 19: КачественныйСкачок(М1, М2).
Определение: Переход М1 -> М2 есть перерыв постепенности,
нарушение одной меры и создание другой (закон II.20).
Области: М1, М2 принадлежат TYP.

Предикат 20: ЧисленныйРасчётТребуется(Г).
Определение: Игра Г требует численного расчёта для решения
(решение матричных игр, задач ЛП, нахождение фронта Парето).
Области: Г принадлежит GAME.

Примечание о заимствовании: области AGENT, TASK, TYP,
SUBJ, PROC заимствуются из базового словаря МФО-НС-13.3.3
(дополнения 12.1-12.3.1) и словаря раздела X.


================================================================================
ЯКОРНЫЕ СВЯЗИ И СТЫКОВКИ (п. I.14.2, I.14.4)
================================================================================

Якорь к Диалектической логике:
Операционализирует закон II.4 (Противоречие как источник
развития) через формализацию конфликта интересов; закон
II.14 (Конкретность истины) через фиксацию множества
стратегий и границ применимости решения; закон II.22
(Практика) через материальное обоснование функций полезности.

Якорь к Формальной логике:
Опирается на строгую структуру выбора (множества стратегий,
классы выбора) и правила вывода, обеспечивая дисциплину
построения цепочек обоснования оптимальных стратегий.

Якорь к Математической логике:
Использует результаты математической логики: теорема
Брауэра (равновесие Нэша), теорема Цермело (многошаговые
игры), основная теорема матричных игр. Теория игр не
является самостоятельной логикой в смысле наличия собственных
аксиом и правил вывода, а является прикладным математическим
аппаратом.

Стыковка с Эпистемической логикой (ЭПИСТ-1.0):
Асимметрия информации между игроками формализуется через
предикат Known(a, фи). Игры с неполной информацией требуют
активации ЭПИСТ-1.0 для фиксации того, что каждый игрок
знает и не знает.

Стыковка с Аргументационной логикой (АРГ-1.0):
Обоснование того, почему агент выбрал именно эту стратегию,
подвергается процедуре аргументационной оценки. Бремя
доказательства лежит на утверждающем оптимальность стратегии.

Стыковка с Деонтической логикой (ДЕОНТ-1.0):
Нормативные ограничения на стратегии формализуются через
деонтические операторы: ЗапрещённаяСтратегия соответствует
оператору F, ОбязательнаяСтратегия — оператору O.

Стыковка с Линейной логикой (ЛИНЕЙН-1.0):
Ресурсы в задачах распределения формализуются через линейную
логику: каждый ресурс используется ровно один раз. Лемма
Гиббса и критерий Гросса операционализируют закон расхода
ресурсов для задач оптимального распределения.

Стыковка с СИНКР-1 (СИНКР-ДИАГ, СИНКР-ТРАНС):
Мифологические драйверы искажают функции полезности.
Предикат МифологическиИскажённаяПолезность формализует
случай, когда функция полезности агента искажена синкретическим
мышлением (контур Т-3 СИНКР-ТРАНС).

Стыковка с ВЕРОЯТ-1.1 (Вероятностная логика):
Смешанные стратегии используют вероятностные оценки.
Предикат СмешаннаяСтратегия связан с вероятностным
распределением на множестве чистых стратегий.

Стыковка с НЧЕТ-1.0 (Нечёткая логика):
Размытые критерии в многокритериальной оптимизации
(например, "высокое качество", "низкая стоимость")
формализуются через нечёткие множества. Дефаззификация
применяется для перевода нечёткого результата в чёткое
решение при выборе оптимальной стратегии.

Стыковка с НМЛ-1.1 (Немонотонная логика):
Пересмотр стратегий при поступлении новой информации
(немонотонный отзыв вывода) формализует изменение
оптимальной стратегии при изменении условий игры.

Стыковка с ПКТ-23 (Качественная типологизация):
Фронт Парето строится только внутри одной качественной
модели. При переходе между моделями фиксируется
КачественныйСкачок и требуется МостТрансляции.

ТРИГГЕРНАЯ ТАБЛИЦА АКТИВАЦИИ (п. I.14.5)
================================================================================

Расширение: Теория игр (ИГРЫ-1.0).

Триггер активации:
1. Наличие в объекте анализа двух и более субъектов с
   противоположными целями (деонтический конфликт или
   различие функций полезности).
2. Многокритериальный запрос (несколько конкурирующих
   критериев).
3. Задача распределения ограниченного ресурса.
4. Иерархическое взаимодействие (центр — производитель,
   лидер — последователь).
5. Нормативные ограничения на стратегии агентов.
6. Детекция синкретического агента (флаг [SINKR_DETECTED]
   из СИНКР-ДИАГ) — в рамках контура Т-1 СИНКР-ТРАНС.
7. Численный расчёт для решения матричных игр, задач ЛП,
   нахождения фронта Парето (активация ВЫЧИСЛ-1.0).

Запрет активации:
1. Объект безагентен (императив 11; запрет 4, п. I.14.6).
2. Никто ничего не решает (чисто стихийный процесс).
3. Объект полностью формализован без противоречий.
4. Подмена вероятности практической верификацией
   (закон II.22, ПМПВ).

Интеграция в МФО:
Дополняет ПМПВ (6.5) на микро/мезо уровнях. Операционализирует
тег [NORMATIVE] (п. 6.10) для нормативных ограничений стратегий.
Связь с деонтической (норма применяется к агенту), эпистемической
(агент знал, что делает), аргументационной (обоснование выбора
стратегии), линейной (ресурсы в играх) логиками.
При численных расчётах обязательна активация ВЫЧИСЛ-1.0.

МОДИФИКАЦИИ СУЩЕСТВУЮЩИХ ПРОТОКОЛОВ МФО-НС-13.3.3
================================================================================

--- 1. Дополнение к протоколу ПМР-20 (п. 6.34) ---
Формализация агентной реализации через теорию игр.

Вопрос М-1 ("Кто реализует?") ужесточается. Недостаточно
просто идентифицировать субъекта. Требуется доказательство
агентного выбора стратегии, а не констатация исторической
неизбежности.

Для всех n, для всех a:
если (Норма(n, D) И Агент(a)),
то существует такая стратегия х в игре Г, что
Реализует(a, n) является результатом выбора стратегии х.

Интерпретация: если норма реализуется, это должно быть
следствием осознанного выбора агента (выбора стратегии
в игре), а не исторической необходимости.

--- 2. Дополнение к протоколу ПАПП-24 / ДВА (п. 6.38) ---
Проверка (г.2): Анализ альтернативных стратегий.

Антитезис обязан включать проверку: "Существует ли
альтернативная стратегия, при которой оцениваемый
институт/право/процедура работает иначе, и как это
влияет на синтез?"

Для всех Г, для всех х:
если РавновесиеНэша(х, Г),
то существует такая стратегия у, что
(не РавновесиеНэша(у, Г)) И (не ДоминирующаяСтратегия(у, Г)).

Интерпретация: если синтез основан на равновесии Нэша,
то антитезис обязан проверить, не существует ли доминирующей
стратегии, которая сделает синтез неоптимальным.

--- 3. Дополнение к протоколу ПМПВ (п. 6.5, этап 3) ---
Картирование структурных интересов через функции полезности.

При детекции конфликта интересов система обязана построить
функции полезности субъектов на основе их материального
положения.

Для всех а1, для всех а2, для всех и1, для всех и2:
если (КонфликтИнтересов(а1, а2) И
     ФункцияПолезности(а1, и1) И
     ФункцияПолезности(а2, и2)),
то существует такая игра Г, что
(ТипИгры(Г, ТИП_АНТАГОНИСТИЧЕСКАЯ) ИЛИ
 ТипИгры(Г, ТИП_БИМАТРИЧНАЯ)) И
ФункцияПолезности(а1, и1) И
ФункцияПолезности(а2, и2) И
ПолезностьВерифицирована(и1) И
ПолезностьВерифицирована(и2).

Интерпретация: при детекции конфликта интересов система
обязана построить функции полезности субъектов на основе
их материального положения. Функции полезности должны быть
верифицированы через ПМПВ (ПолезностьВерифицирована),
а не постулированы априорно.

--- 4. Дополнение к протоколу ПКТ-23 (п. 6.37) ---
Фронт Парето только внутри одной качественной модели.

Построение фронта Парето допустимо ТОЛЬКО внутри одной
качественной модели (по оси "Модель" протокола ПКТ-23).
При переходе между моделями фиксируется КачественныйСкачок
и требуется МостТрансляции.

Для всех С, для всех х:
если (ОптимумПарето(х, С) И ФронтПаретоВычислен(С)),
то ВнутриОднойМодели(С).

Интерпретация: если набор критериев С не принадлежит одной
качественной модели, то построение фронта Парето запрещено.
Вместо этого требуется фиксация качественного скачка
[КАЧЕСТВЕННЫЙ_СКАЧОК] по протоколу ПКТ-23.

--- 5. Дополнение к протоколу ПСВР-Р (п. 6.4) ---
Каскадные эффекты через минимакс.

При анализе каскадных эффектов разрыва узлов графа
материальных потоков может быть применена минимаксная
стратегия для оценки наихудшего сценария.

Для всех е, для всех р, для всех р':
если (Уравнение(е, р) И
     существует такая интервенция и с значением цси, что
     Интервенция(и, р, е, цси) И
     Затронут(р', р)),
то существует такая интервенция и' с значением цси', что
Интервенция(и', р', е, цси') И цси' не равно цси.

Интерпретация: интервенция в процедуру р через механизм е
вызывает изменение в зависимой процедуре р' через тот же
механизм е, но с другим значением. Это формализует каскадный
эффект разрыва узла в графе материальных потоков. Минимаксная
стратегия оценивает наихудший сценарий каскадного эффекта.

--- 6. Обязательная активация ВЫЧИСЛ-1.0 ---
При численных расчётах.

При активации любых численных расчётов, связанных с теорией
игр, ОБЯЗАТЕЛЬНО активируется модуль ВЫЧИСЛ-1.0 для фиксации
вычислительного провенанса.

Численные расчёты включают:
а) Решение матричных игр (нахождение седловых точек,
   минимаксных стратегий, решение через ЛП).
б) Нахождение равновесия Нэша в биматричных играх.
в) Вычисление фронта Парето и множества Слейтера.
г) Решение задач оптимального распределения ресурсов
   (лемма Гиббса, критерий Гросса).
д) Итерационные методы решения непрерывных игр.
е) Численное моделирование многошаговых игр.

Для всех Г:
если ЧисленныйРасчётТребуется(Г),
то существует такое исполнение и такой артефакт, что
ЖурналИсполнения(исполнение, артефакт) И
КодИспользован(Г, артефакт) И
Воспроизводим(артефакт).

Области: Г принадлежит GAME, исполнение принадлежит
COMP_EXEC, артефакт принадлежит COMP_ARTIFACT
(из словаря ВЫЧИСЛ-1.0).

ДИАГНОСТИЧЕСКИЕ ФЛАГИ НАДСТРОЙКИ ИГРЫ-1.0
================================================================================

Все флаги являются строго диагностическими (по модели
FORMAL_INCONSISTENCY, п. V.10 МФО-НС-13.3.3): не входят
в формулу КК_итог (соблюдение антиредукционистского контура
п. 5.8), но влекут генерацию ЭМД и перевод утверждения в
статус REFERENCE_ONLY или EXPERT_REVIEW_REQUIRED.

Флаг 1: [ИГРОВАЯ_МОДЕЛЬ_НЕПРИМЕНИМА]
Условие установки: модель игры не применима к объекту
(безагентный объект, отсутствие конфликта интересов).
Действие: генерация ЭМД; требование пересмотра модели
или деактивация модуля.

Флаг 2: [ПОЛЕЗНОСТЬ_НЕ_ВЕРИФИЦИРОВАНА]
Условие установки: функция полезности не верифицирована
через ПМПВ (этап 3).
Действие: генерация ЭМД; требование верификации через
ПМПВ; перевод вывода в статус HYPOTHETICAL.

Флаг 3: [ПАРЕТО_МЕЖДУ_МОДЕЛЯМИ]
Условие установки: попытка построить фронт Парето между
качественными моделями (нарушение условия
ВнутриОднойМодели(С)).
Действие: блокировка построения; требование фиксации
качественного скачка по ПКТ-23.

Флаг 4: [СТРАТЕГИЯ_НЕДОПУСТИМА]
Условие установки: стратегия не является допустимой в
данной модели игры (отсутствует в множестве стратегий
или запрещена нормой).
Действие: генерация ЭМД; требование пересмотра стратегии
или модели.

Флаг 5: [РАВНОВЕСИЕ_НЕ_ВЕРИФИЦИРОВАНО]
Условие установки: равновесие заявлено, но не верифицировано
через численный расчёт или материальную практику.
Действие: генерация ЭМД; требование верификации через
ВЫЧИСЛ-1.0 или ПМПВ.

Флаг 6: [КОНФЛИКТ_ИНТЕРЕСОВ_НЕ_РАЗРЕШЁН]
Условие установки: конфликт интересов между агентами
обнаружен, но игра не определена (тип игры не установлен).
Действие: генерация ЭМД; требование определения типа игры
и функций полезности.

Флаг 7: [МИФОЛОГИЧЕСКОЕ_ИСКАЖЕНИЕ_ПОЛЕЗНОСТИ]
Условие установки: функция полезности искажена мифологическими
драйверами (через СИНКР-1).
Действие: генерация ЭМД; квалификация мифологического
драйвера как материальной силы (закон II.22); прогноз
поведения по мифологическим драйверам.

Флаг 8: [ВЫЧИСЛИТЕЛЬНЫЙ_ПРОПЕРНАНС_ОТСУТСТВУЕТ]
Условие установки: результат вычислительный (триггер
активирован), минимальный контур не зафиксирован полностью.
Действие: диагностический флаг из модуля ВЫЧИСЛ-1.0.
Ответ не блокируется, но маркируется. В выводе указывается:
"Вычислительный провенанс не зафиксирован; воспроизводимость
не гарантирована."

ГРАНИЦЫ ПРИМЕНИМОСТИ НАДСТРОЙКИ ИГРЫ-1.0
================================================================================

ДЕЙСТВИТЕЛЬНО:

- Формализация конфликтов интересов между субъектами через
  антагонистические и неантагонистические игры.
- Многокритериальная оптимизация (фронт Парето, множество
  Слейтера) внутри одной качественной модели.
- Оптимальное распределение ресурсов (лемма Гиббса, критерий
  Гросса) при наличии верифицированных функций эффективности.
- Иерархические взаимодействия (Штакельберг, Гермейер) для
  моделирования "центр — производитель".
- Деонтические ограничения стратегий через операторы O, P, F
  из ДЕОНТ-1.0.
- Моделирование синкретического мышления и мифологических
  драйверов через СИНКР-1.
- Оценка наихудшего сценария через минимаксные стратегии
  (защита от каскадных эффектов).
- Формализация агентной реализации через выбор стратегии в
  игре (протокол ПМР-20).
- Анализ альтернативных стратегий в антитезисе (ПАПП-24).
- При численных расчётах — обязательная активация ВЫЧИСЛ-1.0.

ЗАПРЕЩЕНО:

- Применение предикатов РавновесиеНэша, ОптимумПарето,
  ФункцияПолезности к безагентным физическим, химическим
  или чисто математическим процессам (императив 11;
  Специальный закон, разд. III МФО-НС-13.3.3).
- Числовая редукция: категорически запрещено преобразовывать
  функции полезности, фронты Парето, распределения Гиббса
  или любые другие предикаты ИГРЫ-1.0 в числовые веса,
  коэффициенты или множители формулы КК_итог
  (антиредукционистский контур п. 5.8).
- Подмена диалектики формализмом: наличие формальной
  структуры выбора (множества стратегий, фронты Парето)
  не заменяет диалектического вскрытия противоречия
  (разд. II МФО-НС-13.3.3) и материально-практической
  верификации (ПМПВ, п. 6.5, закон II.22).
- Подмена практики формализмом: наличие равновесной
  стратегии не доказывает материальную истинность.
  Истинность устанавливается только через протоколы
  ПИР-ЭУ (п. 6.1) и ПМПВ (п. 6.5).
- Применение к безагентным объектам: теория игр
  активируется только при наличии идентифицируемых
  агентов (субъектов) в объекте анализа (запрет 4,
  п. I.14.6; императив 11).
- Построение фронта Парето между качественными моделями
  без фиксации качественного скачка (нарушение закона
  II.20 и протокола ПКТ-23).
- Использование функций полезности, не верифицированных
  через ПМПВ (нарушение закона II.22).
- Трактовка настоящего модуля как новой редакции,
  отменяющей МФО-НС-13.3.3 (единое правило иерархии).
- Горизонтальное смешение с другими расширениями:
  теория игр не заменяет аргументационную логику,
  деонтическую логику или эпистемическую логику,
  а дополняет их по триггерам.

ГРАНИЦЫ (предупреждения):

- Теория игр является формальным инструментом уровня
  Антитезиса и контроля границ применимости. Она не
  заменяет диалектическое снятие противоречия (разд. IV
  МФО-НС-13.3.3), а лишь предоставляет механизм для его
  чёткой фиксации перед разрешением.
- Условные нормы и сложные иерархические игры (более двух
  уровней) в текущей версии не формализуются полностью
  и являются вектором будущего расширения.
- Модуль является экспериментальной надстройкой до
  калибровки по п. 6.9 (корпус не менее 50 кейсов с
  игровыми конфликтами и многокритериальными задачами).
- При численных расчётах обязательна активация ВЫЧИСЛ-1.0.
  Отсутствие провенанса не блокирует ответ, но маркируется
  флагом [ВЫЧИСЛИТЕЛЬНЫЙ_ПРОПЕРНАНС_ОТСУТСТВУЕТ].


================================================================================
ИЛЛЮСТРАТИВНЫЙ ПРИМЕР ПРИМЕНЕНИЯ (СТРУКТУРНЫЙ)
================================================================================

[ПРИМЕР ДЛЯ СТРУКТУРЫ — НЕ ИСПОЛЬЗОВАТЬ]

Предупреждение: данный пример сгенерирован исключительно для
демонстрации формата применения предикатов. Он не является
фактологическим основанием и не должен использоваться для
верификации реальных утверждений (протокол ПЗПФ-01, п. 6.12).

Этап 1. ПМР-20 (Вопрос М-1).
Действие: идентифицирован субъект (Директор), реализующий
норму. Проверяется, является ли это осознанным выбором
стратегии в игре, а не исторической неизбежностью.
Формальная маркировка: Агент(Директор) И Норма(Н, Д) И
существует такая игра Г, что Реализует(Директор, Н)
является результатом выбора стратегии в Г.

Этап 2. ПМПВ (Этап 3, картирование структурных интересов).
Действие: построение функций полезности для двух агентов
(Директор и Акционер) на основе их материального положения.
Формальная маркировка: КонфликтИнтересов(Директор, Акционер).
ФункцияПолезности(Директор, и1). ФункцияПолезности(Акционер, и2).
ПолезностьВерифицирована(и1). ПолезностьВерифицирована(и2).

Этап 3. ИГРЫ-1.0 (определение типа игры).
Действие: конфликт интересов формализуется как биматричная
игра. Определяются стратегии и матрицы выигрышей.
Формальная маркировка: ТипИгры(Г, ТИП_БИМАТРИЧНАЯ).

Этап 4. ИГРЫ-1.0 (поиск равновесия).
Действие: поиск равновесия по Нэшу в биматричной игре.
Активация ВЫЧИСЛ-1.0 для численного расчёта.
Формальная маркировка: РавновесиеНэша(х, Г).
ЧисленныйРасчётТребуется(Г).

Этап 5. ПАПП-24 (Антитезис, проверка г.2).
Действие: проверка существования альтернативной стратегии,
при которой синтез меняется.
Формальная маркировка: если РавновесиеНэша(х, Г),
то существует такая стратегия у, что не РавновесиеНэша(у, Г)
и не ДоминирующаяСтратегия(у, Г).

Этап 6. ПКТ-23 (фронт Парето внутри модели).
Действие: построение фронта Парето для множества стратегий
внутри одной качественной модели.
Формальная маркировка: ОптимумПарето(х, С).
ВнутриОднойМодели(С).

Этап 7. Флаг [ПОЛЕЗНОСТЬ_НЕ_ВЕРИФИЦИРОВАНА].
Действие: если функция полезности агента не верифицирована
через ПМПВ, устанавливается флаг и вывод переводится в
статус HYPOTHETICAL.

Этап 8. Флаг [ВЫЧИСЛИТЕЛЬНЫЙ_ПРОПЕРНАНС_ОТСУТСТВУЕТ].
Действие: если численный расчёт выполнен без фиксации
провенанса, устанавливается флаг из модуля ВЫЧИСЛ-1.0.
